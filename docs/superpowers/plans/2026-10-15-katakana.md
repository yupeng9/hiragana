# Katakana Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add katakana to the app: a script switch, katakana quiz/chart/words/progress, a katakana example-word list, and a Review reading aid that follows katakana (and small-kana) progress.

**Architecture:** Katakana rows are derived from the hiragana rows (`+0x60`), so data stays in one place. A `settings.script` / `settings.krows` pair selects the script and its learned rows; one `knownChars(state)` helper feeds both word filtering and Review's romaji ruby. Pitch rendering switches from counting characters to counting morae.

**Tech Stack:** Vanilla ES modules, `node --test` (run as `npm test`), Playwright via `page.route` for browser checks.

**Spec:** `docs/superpowers/specs/2026-10-15-katakana-design.md`

**Conventions for every task:** run `npm test` before committing. Any task that adds or changes a file under `js/`, `css/` or `index.html` ends with `npm run bump-sw` before its commit (the `sw` test fails on a stale VERSION). Tasks that add a *new* file also add it to `FILES` in `sw.js`. Use `git add` with explicit paths. Do not push; publishing is the last task and needs the user's go-ahead.

// Pitch is counted in morae: small ゃゅょ and small vowels join the kana before them, while
// っ, ー and ん are morae of their own.
const JOINS_PREVIOUS = new Set("ゃゅょぁぃぅぇぉャュョァィゥェォ");
export function morae(text) {
  const out = [];
  for (const ch of [...text.normalize("NFC")]) {
    if (out.length && JOINS_PREVIOUS.has(ch)) out[out.length - 1] += ch;
    else out.push(ch);
  }
  return out;
}
```

export const activeScript = state => (state.settings.script === "kata" ? "kata" : "hira");

// Hiragana always has at least the default rows; katakana starts with none learned.
export function activeRows(state, script = "hira") {
  const raw = state.settings[script === "kata" ? "krows" : "rows"];
  const rows = Array.isArray(raw) ? raw.filter(id => ROW_IDS.has(id)) : [];
  return script === "kata" || rows.length ? rows : [...DEFAULT_ROWS];
}

// Every character the learner has met: learned rows of both scripts, the long-vowel mark, and
// each small kana whose full-size kana is learned. Drives word filtering and the Review reading aid.
export function knownChars(state) {
  const known = new Set(["ー"]);
  for (const script of ["hira", "kata"]) {
    const learned = new Set(activeRows(state, script));
    for (const row of scriptRows(script)) {
      if (learned.has(row.id)) for (const c of row.chars) if (c) known.add(c[0]);
    }
  }
  for (const [small, base] of Object.entries(SMALL_BASE)) if (known.has(base)) known.add(small);
  return known;
}
```
